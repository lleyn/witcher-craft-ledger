# Craft Ledger

Статический помощник по ремеслу и алхимии для **The Witcher TRPG**. Работает полностью в браузере и подходит для GitHub Pages.

## Возможности

- 276 ремесленных чертежей и алхимических формул;
- полный русский перевод названий рецептов, компонентов, алхимических субстанций и времени изготовления;
- поиск и фильтры по ремеслу, алхимии и разделам;
- поиск работает как по русским, так и по исходным английским названиям;
- корзина рецептов с количеством партий, суммарными ингредиентами, стоимостью и временем работ;
- выбор количества производимых партий;
- переключение «купить / изготовить» для компонентов, у которых есть собственный рецепт;
- рекурсивное дерево вложенного производства;
- выбор конкретного ингредиента для каждой алхимической субстанции;
- предварительная себестоимость, агрегированный список закупки и сравнение с инвестициями/рыночной ценой из источника;
- адаптивный интерфейс без сервера, базы данных и аккаунта.

## Данные

Нормализованный каталог собран из общественного справочника [The Witcher TRPG Complete Craftsman's Catalogue by SorrowChant](https://docs.google.com/spreadsheets/d/1-kthEEQi65yscW7I8vHZbzvueOoPCV5neIW3TBZgv9o/edit?usp=sharing), который заявлен автором как свод книг, дополнений и бесплатных DLC. Чистые алхимические субстанции и их двойная эффективность дополнены по официальному бесплатному DLC [A Professional's Tools](https://rtalsoriangames.com/wp-content/uploads/2022/05/RTG-WI-DLC-AProfessionalsTools.pdf). Шесть намеренно исключённых автором свода рецептов возвращены по официальному DLC [Witcher Prostheses and Wheelchairs](https://rtalsoriangames.com/wp-content/uploads/2022/07/RTG-WI-DLC-ProsthesesandWheelchairs.pdf). В текущей версии: 202 ремесленных рецепта, 74 алхимических рецепта и 208 ценовых позиций.

Алхимические компоненты, представленные в исходной таблице пиктограммами, извлекаются по типу субстанции. Две отсутствующие в ценовых листах позиции (`Etching Oil` и `Ruby Dust`) отмечены знаком `≈`; их цены выведены из опубликованных инвестиционных сумм соответствующих рецептов.

Исходные книги остаются главным источником правил. Сводная таблица может содержать опечатки и расхождения, поэтому расчёт на сайте обозначен как предварительный.

Повторная генерация каталога:

```powershell
python scripts/extract_catalog.py path\to\catalog.xlsx src\data\catalog.generated.json
```

## Разработка

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
npm test
```

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и отправьте код в ветку `main`.
2. В **Settings → Pages** выберите источник **GitHub Actions**.
3. Workflow `Deploy Craft Ledger to GitHub Pages` соберёт и опубликует сайт.

Vite использует относительные пути, поэтому проект работает как в корне `username.github.io`, так и по адресу `username.github.io/repository/`.

## Правовой статус

Это бесплатный неофициальный помощник, не замена книгам правил и не одобрен R. Talsorian Games или CD PROJEKT. The Witcher и связанные товарные знаки принадлежат их правообладателям. Исходный код интерфейса не включает художественные тексты или изображения из книг.
